THE MISSING QUESTION // POLICY.TXT

Privacy Policy

Last updated: September 6, 2026

The Missing Question is a developer-focused reasoning tool. It analyzes text you provide to surface one high-leverage unanswered question and can evaluate whether that concern was addressed.

What you send

When you use the web app or MCP tools, you may send product ideas, architecture notes, code-related context, project plans, a proposed resolution, and related text needed to perform the analysis.

Do not send passwords, API keys, authentication tokens, private keys, or other secrets. Avoid sending personal or confidential information unless you have the right to share it and are comfortable having it processed by the services described below.

How your content is processed

The service sends the text needed for analysis to OpenRouter, which routes the request to the configured Nemotron model provider. Requests are configured to use only provider endpoints that OpenRouter marks as not collecting user data (data_collection: deny).

OpenRouter may process request metadata such as model, token counts, timing, and latency. Model providers necessarily process the submitted text to generate the requested analysis.

What this service stores

The Missing Question does not currently use a database and does not intentionally persist your project context, resolutions, or model responses after a request completes.

Infrastructure providers may process ordinary operational and security logs needed to run the service. The service is currently hosted on Render.

Accounts and authentication

The current public prototype does not require a The Missing Question account and does not use OAuth. ChatGPT, Codex, or another MCP client may separately process conversation context under that product's own terms and settings.

Third-party services

The service currently relies on:

  • Render for application hosting.
  • OpenRouter for model routing and inference access.
  • A Nemotron model provider selected through OpenRouter under the configured data-policy restriction.

Those providers operate under their own terms and privacy policies.

Purpose and sharing

Submitted content is used to provide the requested analysis and patch evaluation. The Missing Question does not sell user content or build advertising profiles from submitted project context.

Retention and deletion

Because this service does not intentionally store submitted project context in a database, there is no application-level conversation history to delete. If persistent storage is added later, this policy will be updated before that change is represented as part of the public service.

Children

The Missing Question is a developer tool and is not directed to children under 13.

Changes

This policy may change as the product gains features, providers, authentication, or storage. The current version and update date will remain available on this page.

Contact and support
